# 運賃記録

電車・バス・タクシーの移動を記録し、交通費精算書（PDF）を作る iPhone / Android アプリ。

## できること

- **スタート／移動完了**：GPSで出発地・到着地を取得し、移動中のルートを記録して地図に表示
- **交通機関の選択**：電車・バス・タクシー・その他。乗り継ぎは区間を追加して入力
- **近くの駅・バス停の候補**：記録した位置の近くにある駅やバス停を一覧から選べる（OpenStreetMap）
- **交通系ICカードの取り込み**：Suica・PASMO・ICOCA などをスマホにかざすと、直近20件の利用履歴から電車・バスの運賃を取り込む
- **タクシー**：料金は手入力。領収書の写真を添付できる
- **締め日**：「1日〜月末」と「16日〜翌月15日」から選べる
- **PDF・印刷**：期間ごとの交通費精算書（氏名・所属・社員番号・用務先・目的・区間・金額・承認欄）を作り、印刷・共有できる

## ビルド

GitHub Actions（`.github/workflows/build.yml`）でビルドする。

- Android：`FareLog-android-apk` アーティファクトの APK をインストール
- iPhone：`FareLog-ios-unsigned` は署名なし（コンパイル確認用）。実機に入れるには Apple Developer Program への登録と署名の設定が必要
